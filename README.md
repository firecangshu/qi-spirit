# 炁灵 QILING · 音频驱动数字生命

> 一团由约 9000 个粒子聚合而成的「数字生物」：在没有输入时自主呼吸、游弋、震动；接入音频后随音乐的节拍、能量与旋律起舞。纯前端、零后端、单文件即可运行。

## 演示

- 推荐直接双击打开根目录的 **`index.html`**（贴图已内嵌，file:// 离线可用）
- 或起本地服务：`python -m http.server 3083` 后访问 `http://127.0.0.1:3083/index.html`
- `qiling_1.0_demo.html` 为源码主文件（外部引用 three.min.js 与 vendor/，便于二次开发）

## 特性

- **音频驱动**：内置多首曲目（欢乐颂/致爱丽丝/小星星/卡农/天鹅湖/月光）、节拍器、上传本地音频、麦克风实时输入；FFT 频谱 + 能量包络 + 起音检测驱动粒子运动
- **劲舞式节拍编舞**：起音包络自相关测 BPM（50Hz 重采样时间轴 + 对数高斯先验）→ 相位锁定 → 4/4 强弱拍网格上每 8 拍切换动作母题（脉冲/摆动/旋身/弹跳）
- **11 种情绪形态**：睡觉/恐惧/舒服/开心/难过/生气/兴奋/害羞/心动/思考/呼噜，各对应一套粒子运动学参数与专属颜色
- **8 种扩展形态**：龙卷风/沙丁鱼群/魔鬼鱼/水波纹/双螺旋DNA/鲸喷/桃花水母/黑洞
- **7 种粒子素材**：柔光尘（默认）/柔光生命核/半透明活体膜/褶皱金属碎箔/柔性哑光金属/多孔细胞甲片/光纤种子，另有**萤火虫特效**（大多数固定悬停闪烁、少数带彗尾飞行，占比可调）
- **个性化情绪档案**：盲测校准情绪映射 + 逐情绪取色，档案码导出/导入，本地持久化
- **渲染管线**：贴图 256² POT dataURL 内嵌 + mipmap/各向异性、自定义 ShaderMaterial（逐粒子尺寸/旋转/明暗差异）、UnrealBloom 后期辉光、边缘径向渐隐、密度自适应防过曝、渲染分辨率拉满 + FPS 自适应降档
- **双向安全阈值（SAFETY GATE）**：对音频能量做归一化与上下限钳制，无论音频多强，数字生命都被约束在画面边界内
- **形态自然过渡**：任意切换都在约 1 秒内做形变插值（morph），而非瞬间跳变
- **兼容性**：优先 WebGL（Three.js）渲染，当前环境无 WebGL 时自动降级为 Canvas 2D 渲染

## 控制面板

右侧可折叠分组（开合与滑杆状态本地记忆）：💗情绪预览（自主随机切换开关）→ 🧪扩展形态库 → ✨粒子效果（粒子形态/贴图素材/颗粒差异/粒子大小/变化速度/拖尾占比）→ 🎨情绪颜色（逐情绪实时取色）→ 🎵音频输入 → 🎛参数（灵敏度）。左侧为盲测卡与 SAFETY GATE 监视卡，均可折叠。

## URL 直达参数

- `?st=状态` / `?state=状态`：锁定某个情绪或形态（如 `?st=implode`、`?state=swimming`）
- `?pt=素材`：直达某粒子素材（如 `?pt=firefly`）
- `?tr=占比`：萤火虫拖尾占比（0.04~0.3）
- `?automusic=1` / `?autobeat=1`：自动播放名曲 / 节拍器

## 技术栈

- 渲染：Three.js r128（WebGL）＋ Canvas 2D 降级；后期：UnrealBloomPass
- 音频：Web Audio API（AnalyserNode / FFT / 频谱通量起音检测 / 自相关 BPM / 相位锁定）
- 架构：纯前端单页，驱动层（音频分析 → 运动参数）与表现层（粒子形态）解耦
- 无构建步骤、无 npm 依赖、无后端

## 二次开发

编辑 `qiling_1.0_demo.html`（需与 `three.min.js`、`vendor/` 放在同一目录）。新增粒子素材只需三步：`PARTICLE_IMG` 加 dataURL、`PARTICLE_RENDER` 配渲染性格（count/size/opacity/additive）、贴图素材区加按钮。新增形态：注册形态 key → 配置元信息与配色 → 在主粒子循环中新增参数化分支。
