# 炁灵 QILING · 音频驱动数字生命
> QILING — An Audio-Driven Digital Lifeform

> 一团由约 9000 个粒子聚合而成的「数字生物」：有基因、有族群、有心智、可触摸。没有输入时自主呼吸、游弋、走神；接入音频后随音乐的节拍、能量与旋律起舞；按住鼠标左键，整群粒子会像铁屑遇到磁铁一样涌向你的指尖。纯前端、零后端、单文件即可运行。

## 三级生命引擎 Three-Stage Life Engine

### P0 · 胚胎计划（基因系统） Embryo Plan — Genetics
- **32 位基因出生码**：每只炁灵由 8 位十六进制码唯一决定——色相带 / 体质 / 呼吸深度与频率 / 活泼 / 黏人 / 好奇 / 沉稳，同码同名永不错乱
- **称号与稀有度**：普通 / 稀有（约 1%）/ 传说（约 0.1%），称号由基因确定性推导（如「醉月·霁青」），看名知色
- **基因卡（出生证明）**：点击顶部身份条弹出——色相带 + 六维性格可视化 + 稀有度 + 一键复制孵化链接
- **孵化直达**：URL 带 `?g=出生码`（如 `?g=80000000`）即可孵化指定基因的炁灵

### P1 · 涌现引擎（族群自组织） Emergence Engine — Tribal Self-Organization
- 粒子自动分成 4 个族群，按这只炁灵独有的 **4×4 基因社交矩阵**互相吸引/排斥——群体结构是「长」出来的，不是编出来的
- 音乐低音越强，族群凝聚力越强；面板「涌现强度」滑杆实时调节（本地记忆）

### P2 · 心智引擎（连续情绪 + 内在动机） Mind Engine — Continuous Emotion & Inner Motivation
- 情绪不再是开关，而是「效价×唤醒」二维平面上**连续漂移的一个点**：11 种状态各占一片"心境区域"，情绪点漂到哪就呈现哪种状态
- **音乐推它**：亮度→高昂/低落，能量+鼓点→激动/平静；4 秒驻留 + 滞回防抖
- **空闲走神**：没音乐时好奇心（基因）与疲劳电池驱动它自主漫游换状态，7–10 秒换一个心思
- **情绪罗盘**：情绪预览卡内嵌发光罗盘，亮点=当前心情、拖尾=漂移轨迹，你能亲眼看到它的心在动
- 基因深度联动：好奇→游荡半径 · 活泼→切换节奏 · 黏人→音乐响应 · 沉稳→漂移速度

### 触觉交互 · 磁吸 Magnetic Touch
- **按住左键基本不动**：粒子约 0.3 秒吸附到指尖，聚成一团会呼吸颤动的"活球"
- **按住慢慢移动**：指针即磁极，拖着整群粒子"遛弯"
- **按住快速拖动**（>8px）：自动转为旋转视角，两不误
- **松开左键**：约 0.5 秒弹性衰减，粒子游回原形态

- 设计令牌系统（改一处=全站换肤）、更纱黑体 Sarasa Gothic SC、统一弹簧动效语言

## 基础特性 Core Features

- **音频驱动**：内置多首曲目（欢乐颂/致爱丽丝/小星星/卡农/天鹅湖/月光）、节拍器、上传本地音频、麦克风实时输入；FFT 频谱 + 能量包络 + 起音检测驱动粒子运动
- **劲舞式节拍编舞**：起音包络自相关测 BPM（50Hz 重采样时间轴 + 对数高斯先验）→ 相位锁定 → 4/4 强弱拍网格上每 8 拍切换动作母题（脉冲/摆动/旋身/弹跳）
- **11 种情绪形态**：睡觉/恐惧/舒服/开心/难过/生气/兴奋/害羞/心动/思考/呼噜，各对应一套粒子运动学参数与专属颜色
- **8 种扩展形态**：龙卷风/沙丁鱼群/魔鬼鱼/水波纹/双螺旋DNA/鲸喷/桃花水母/黑洞
- **7 种粒子素材**：柔光尘（默认）/柔光生命核/半透明活体膜/褶皱金属碎箔/柔性哑光金属/多孔细胞甲片/光纤种子，另有**萤火虫特效**（大多数固定悬停闪烁、少数带彗尾飞行，占比可调）
- **个性化情绪档案**：盲测校准情绪映射 + 逐情绪取色，档案码导出/导入，本地持久化
- **渲染管线**：贴图 256² POT dataURL 内嵌 + mipmap/各向异性、自定义 ShaderMaterial（逐粒子尺寸/旋转/明暗差异）、UnrealBloom 后期辉光、边缘径向渐隐、密度自适应防过曝、渲染分辨率拉满 + FPS 自适应降档
- **双向安全阈值（SAFETY GATE）**：对音频能量做归一化与上下限钳制，无论音频多强，数字生命都被约束在画面边界内
- **形态自然过渡**：任意切换都在约 1 秒内做形变插值（morph），而非瞬间跳变
- **兼容性**：优先 WebGL（Three.js）渲染，当前环境无 WebGL 时自动降级为 Canvas 2D 渲染

## URL 直达参数 URL Params

- `?g=出生码`：孵化指定基因的炁灵（如 `?g=80000000`）
- `?st=状态` / `?state=状态`：锁定某个情绪或形态（如 `?st=implode`、`?state=swimming`）
- `?pt=素材`：直达某粒子素材（如 `?pt=firefly`）
- `?tr=占比`：萤火虫拖尾占比（0.04~0.3）
- `?automusic=1` / `?autobeat=1`：自动播放名曲 / 节拍器

## 技术栈 Tech Stack

- 渲染：Three.js r128（WebGL）＋ Canvas 2D 降级；后期：UnrealBloomPass
- 音频：Web Audio API（AnalyserNode / FFT / 频谱通量起音检测 / 自相关 BPM / 相位锁定）
- 生命系统：32 位基因表达（色相/体质/呼吸/性格）· 4 族群基因社交矩阵（涌现）· 效价×唤醒连续情绪空间 + 内在动机（心智）
- 交互：指针三维精确交点定位 + 持久偏移场磁吸（8px 阈值区分旋转）
- 可见性保障：尺寸保底（≥基准 45%）· 情绪色感知亮度下限（Rec.709 Y≥0.36，蓝紫不再发暗）· 贴图亮度归一化（可见像素均亮 <0.72 自动放缩）· 发光混合对比增益 ×2.0
- 架构：纯前端单页，驱动层（音频分析 → 运动参数）与表现层（粒子形态）解耦
- 无构建步骤、无 npm 依赖、无后端

## 二次开发 Secondary Development

编辑 `qiling_1.0_demo.html`（需与 `three.min.js`、`vendor/` 放在同一目录）。新增粒子素材只需三步：`PARTICLE_IMG` 加 dataURL、`PARTICLE_RENDER` 配渲染性格（count/size/opacity/additive）、贴图素材区加按钮。新增形态：注册形态 key → 配置元信息与配色 → 在主粒子循环中新增参数化分支。

常用调参点（文件内搜索定位）：磁吸阈值 `MAG_T=8` · 吸附速度 `dt*6.0` · 漫游周期 `dwellT>7` · 情绪感知亮度线 `Y>=0.36` · 贴图亮度线 `0.72` · 发光增益 `lit*2.0`。
