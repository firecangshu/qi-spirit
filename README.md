# 炁灵 QILING · 音频驱动数字生命

> 一团由粒子聚合而成的「数字生物」：在没有输入时自主呼吸、游弋、震动；接入音频后，随音乐的节拍、能量与旋律起伏而舞动。纯前端、零后端，打开网页即可运行。

## 演示

直接用浏览器打开根目录的 **`index.html`**（已内联 Three.js，单文件、离线可跑，无需服务器、无需安装依赖）。

## 特性

- **音频驱动**：内置经典名曲、节拍器、上传本地音频、麦克风实时输入四种音源；经 FFT 频谱 + 能量包络 + 节拍检测驱动粒子运动，而非简单地用音量缩放。
- **双向安全阈值（SAFETY GATE）**：对音频能量做归一化与上下限钳制，无论音频多强，数字生命都被约束在画面边界内，不会冲出屏幕。
- **11 种情绪形态**：睡觉 / 恐惧 / 舒服 / 开心 / 难过 / 生气 / 兴奋 / 害羞 / 心动 / 思考 / 呼噜，每种情绪对应一套独特的粒子运动学参数。
- **个性化情绪档案**：通过「盲测」让用户凭直觉把粒子动态标注为自己理解的情绪，并选择专属配色，生成只属于自己的炁灵；档案可导出 / 导入编码、本地存储。
- **8 种扩展形态实验**：龙卷风、沙丁鱼群、魔鬼鱼、水波纹（沙漠震动）、双螺旋 DNA、鲸喷、桃花水母、黑洞。
- **形态自然过渡**：任意切换都在约 1 秒内做形变插值（morph），而非瞬间跳变。
- **视觉皮肤可插拔**：粒子群 / 流体金属 / 半透明胶质 / 机械细胞等表现层与驱动层解耦，可替换。
- **兼容性**：优先 WebGL（Three.js）渲染，当前环境无 WebGL 时自动降级为 Canvas 2D 渲染，保证低端设备 / 内嵌浏览器也能看到。

## 技术栈

- 渲染：Three.js（WebGL）＋ Canvas 2D 降级
- 音频：Web Audio API（AnalyserNode / FFT / 能量包络 / 节拍检测）
- 架构：纯前端单页，驱动层（音频分析 → 运动参数）与表现层（粒子形态）解耦
- 无构建步骤、无 npm 依赖、无后端

## 二次开发

编辑 `qiling_1.0_demo.html`（需与 `three.min.js` 放在同一目录）。新增一个形态只需：注册形态 key → 配置元信息与配色 → 在主粒子循环中新增一个参数化分支（输出每个粒子的目标坐标），形态过渡会自动获得。

## 说明
